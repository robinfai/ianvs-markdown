# ianvs_markdown_clipboard

Optional native clipboard output for Flutter hosts that need both Markdown
plain text and semantic HTML on the same clipboard item. It uses
`super_clipboard` and falls back to the complete Markdown if native output is
unavailable or fails. A failure of the plain fallback is reported to the caller.

This adapter is currently an **unpublished source package** (`publish_to: none`).
Use a local checkout while evaluating the candidate; a future registry version
and platform claims must pass the R3 release gates. The core `ianvs_markdown`
package does not depend on it. The adapter accepts strings and does not depend
on a particular core package version.

```yaml
dependencies:
  ianvs_markdown_clipboard:
    path: /path/to/ianvs-markdown/packages/ianvs_markdown_clipboard
```

```dart
import 'package:ianvs_markdown/ianvs_markdown.dart';
import 'package:ianvs_markdown_clipboard/ianvs_markdown_clipboard.dart';

Future<void> writeRich(IanvsMarkdownClipboardData data) =>
    writeIanvsMarkdownRichClipboard(markdown: data.markdown, html: data.html);

// Use the same callback with IanvsMarkdown or IanvsMarkdownLiveEditor.
IanvsMarkdownView(data: source, clipboardWriter: writeRich);
```

Supply HTML generated by the component or sanitized by the host. The adapter
does not parse or transform either representation. It writes both on one item,
preserving the existing Markdown-copy behavior for plain-text destinations.
This writer applies to document reading selections; Source mode retains
Flutter's editable-text copy behavior.

On the currently verified macOS path, native compilation needs Xcode,
CocoaPods and Rust/Cargo. Other plugin targets are not automatically verified
by the adapter. [Platform evidence](../../doc/PLATFORM_SUPPORT.md) and
[cost/decision/migration notes](../../doc/CLIPBOARD_DEPENDENCY_DECISION.md)
separate build results from real cross-application paste acceptance.

From this directory, run `flutter pub get`, `flutter analyze`, `flutter test`.
From the repository root, `make test-clipboard` runs the native/fallback
contracts; `make check-integrations` includes them plus the migrated Linefold
and Mermaid hosts. Tests use a fake native writer and do not modify the OS
clipboard. Real destination-app paste remains an R3-01 acceptance item.
