# 基础 Markdown 节点 Live Preview 对照审计

## 范围与方法

- 参考端：Obsidian 1.13.7，编辑视图 Live Preview。
- 实现端：Ianvs Markdown Playground，Preview 实时预览编辑模式。
- 探针：`basic-markdown-nodes.md`。
- 覆盖：ATX 标题、Setext 标题、普通段落、粗体、斜体、删除线、高亮、行内代码、链接、引用块、无序列表、有序列表、任务列表、围栏代码块、缩进代码块、GFM 表格、主题分隔线。
- 不在范围：HTML 节点及其控件行为。
- 两端窗口均为 1225 × 768；主题色、字体家族及应用外壳不同，因此结论只校准节点投影、focus/blur 切换、源码标记展开和布局稳定性，不要求跨主题像素同色。

## 结论

| 节点类型 | blur 对照 | focus 对照 | 结果 |
| --- | --- | --- | --- |
| ATX / Setext 标题 | 保持标题层级与标题导轨 | 展开 `#` 或 Setext 源码，不显示额外层级徽标 | 已校准；移除 Ianvs 独有的 `H1–H6` 徽标 |
| 普通段落 | 保持行内投影 | 当前插入点进入原位编辑 | 对齐 |
| 粗体 | 隐藏 `**` | 光标进入后只展开当前 `**bold**` | 对齐 |
| 斜体 | 隐藏 `*` | 光标进入后只展开当前 `*italic*` | 对齐 |
| 删除线 | 隐藏 `~~` | 光标进入后只展开当前 `~~strike~~` | 对齐 |
| 高亮 | 隐藏 `==` | 光标进入后只展开当前 `==highlight==` | 对齐 |
| 行内代码 | 保持代码投影 | 光标进入后展开反引号 | 对齐 |
| 链接 | 显示标签、隐藏目标 | 光标进入后展开完整 Markdown 链接源码 | 对齐；较大宿主字体会让目标换行，不影响源码或选择映射 |
| 引用块 | 隐藏 `>`，保持引用表面和导轨 | 只展开当前物理行的 `>` | 对齐 |
| 无序列表 | 保持视觉项目符号 | 当前项原位编辑，项目符号不跳变 | 对齐 |
| 有序列表 | 保持视觉序号 | 当前项原位编辑，序号不跳变 | 对齐 |
| 任务列表 | 保持复选框投影 | 文本 focus 时复选框仍保留 | 对齐 |
| 围栏代码块 | 保持代码画布与语言标签 | 展开围栏和语言源码，画布不消失 | 对齐 |
| 缩进代码块 | blur 时显示去缩进后的代码 | focus 时恢复精确缩进并显示当前行导轨 | 对齐 |
| GFM 表格 | 保持紧凑网格 | 只激活当前单元格，网格不切成整块源码 | 已校准；修复从其他活动块切入表格时的焦点交接 |
| 主题分隔线 | 显示水平线 | 点击后选择完整 `---` 源码 | 对齐 |

## 校准项

1. 普通块的最小高度由 36 调整为 24，保留围栏代码块和引用块的 36 高度，使段落与列表的 blur/focus 节奏接近 Obsidian。
2. 移除活动标题的 `H1–H6` 徽标，仅保留 Markdown 标记和层级样式。
3. 表格单元格获得焦点前清理旧活动块，避免整张表退化为原始 Markdown 编辑器。
