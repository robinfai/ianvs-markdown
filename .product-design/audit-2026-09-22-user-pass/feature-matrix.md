# 功能与 Markdown 细节矩阵

范围：当前 macOS Linefold 桌面应用；同时核对组件能力与宿主是否接入。共 58 个能力分组，覆盖当前入口和主要语法类别，不把分组数当作穷尽输入组合的证明。

证据标记：**U** = 本轮真实 UI 操作；**T** = 对应自动测试随完整套件通过；**C** = 当前代码核对。某项有多个标记时，仍以“结果/边界”列说明真实操作到哪一步。

## 桌面功能（A01–A24）

| ID | 功能与入口 | 结果 / 边界 | 证据 |
| --- | --- | --- | --- |
| A01 | 新建文档：加号、File、⌘N | 创建独立文档；空 Live/Source 有提示，Read 无写作提示。 | U/T |
| A02 | 打开文件：File → Open、⌘O | 支持多文件路径入口；类型含 md、markdown、mdown、mkd、txt。UI 打开样本，批量和去重由控制器测试覆盖。 | U/T/C |
| A03 | 打开文件夹：侧栏目录按钮、⌘⇧O | 原生目录选择器；工作区文件树可展开。 | U |
| A04 | 文件树 | 目录按需加载，筛出可接受的文本类型；隐藏目录不进入树；Nested 可进入。 | U/T/C |
| A05 | 文件名搜索 | 中文名称、嵌套路径结果和无结果状态可见；不是正文全文搜索。 | U/T |
| A06 | 保存：⌘S | 原生保存对话框、取消、再次保存、Saved 状态和文件树刷新可用。 | U/T |
| A07 | 另存为：⌘⇧S | 独立入口；新路径、监听切换、并发保存与取消由测试覆盖。本轮未穷尽原生另存为对话框组合。 | T/C |
| A08 | 关闭文档：关闭按钮、⌘W | 有未保存关闭处理；保存取消不应丢失草稿。控制器与界面测试覆盖；未对既有用户草稿执行丢弃。 | T/C |
| A09 | 标签切换 | 每份文档保留编辑状态；当前文档在多标签与窗口收窄时滚入可见区。 | U/T |
| A10 | 标签重排 | 可拖动重排；顺序影响快捷键。控制器测试覆盖，本轮未逐种拖动落点复验。 | T/C |
| A11 | 全部文档菜单、⌘1–9 | 菜单展示所有打开文档及前九个快捷键；快捷键映射文档而非模式。 | U/T |
| A12 | Live / Source / Read | 鼠标和 View 菜单切换；同一份 Markdown 模型。模式按钮提供名称、选择态和可激活语义。 | U/T |
| A13 | 侧栏与大纲显隐 | 工具栏、View 菜单；侧栏还有 ⌘⌃S。入口核对，窗口尺寸变化已实际操作。 | T/C/U |
| A14 | 标题大纲 | ATX / Setext 大纲与当前章节显示；Live、Source、Read 的远距离定位实际通过。 | U/T |
| A15 | 外观切换 | 浅色与深色可切换；本轮修复重复解析导致的标题与任务状态错误。外观尚不持久化。 | U/T/C |
| A16 | 撤销 / 重做 | 文档级历史；真实任务、表格、Reload 后 Undo 通过；Read 的改写快捷键被拦截。 | U/T |
| A17 | 剪切 / 复制 / 粘贴 / 全选 | 原生菜单和快捷键；中文、emoji、多行纯文本粘贴实际通过。跨块 Markdown/HTML 双格式复制由测试覆盖，未实测跨第三方应用粘贴。 | U/T |
| A18 | 外部文件变化 | 变更条提供 Keep My Changes / Reload；真实外部写入、Reload、Undo 找回草稿通过。监听时序与删除等边界由测试覆盖。 | U/T |
| A19 | 会话与恢复 | 打开文档、未存草稿、路径、模式、工作区、栏位状态恢复；异常路径与冲突由测试覆盖。光标/滚动偏移未跨启动序列化。 | T/C |
| A20 | Finder 拖入文件 | DropTarget 已接 openPaths；本轮未进行真实 Finder 拖放，不能记为 UI 已验收。 | C |
| A21 | 格式与状态栏 | words、characters、Saved/Edited、UTF-8、LF/CRLF；CRLF 实际编辑保存保持已有换行。编码/换行不是转换控件。 | U/C |
| A22 | 原生菜单和窗口 | File/Edit/View/Window 命令接入；实际打开菜单、缩放窗口。当前运行时 Enter Full Screen 显示禁用，未把全屏记为通过。 | U/C |
| A23 | 文内查找、替换、导出 | 当前桌面无入口；文件名搜索不能替代全文查找。 | C |
| A24 | 格式命令可发现性 | 组件有格式工具栏，桌面将其隐藏。⌘B / ⌘I / ⌘K 可用并有测试，菜单中没有完整格式操作清单。 | T/C |

## Markdown 阅读与编辑（M01–M26）

| ID | 语法 / 场景 | 结果 / 重要细节 | 证据 |
| --- | --- | --- | --- |
| M01 | 中文、英文、emoji、普通段落 | Unicode 样本可显示和保存；真实粘贴不等于中文输入法组合过程已验证。 | U/T |
| M02 | 普通软换行、硬换行、空白段 | 两空格硬换行实际检查；空白间距、反斜线硬换行和多行边界有测试。Live 普通段聚焦前后几何稳定。 | U/T |
| M03 | ATX / Setext 标题 | 显示、样式和大纲可用；仅 marker、嵌套容器、重复标题和折叠模型等由测试覆盖。主题切换回归已修复。 | U/T |
| M04 | 粗体、斜体、粗斜体 | Live 临近光标揭示语法，Read 渲染；定界符组合、跨行和单词内下划线由测试覆盖。 | U/T |
| M05 | 删除线与高亮 | ~~删除线~~、==高亮== 实际显示；匹配/未闭合/转义细节由测试覆盖。 | U/T |
| M06 | 行内代码、转义 | 反引号、转义星号实际检查；多反引号、跨行空白、边界及代码内其他语法保持字面值由测试覆盖。 | U/T |
| M07 | 无序列表、嵌套列表 | 圆点、层级引导线与内层编号可见；松散列表、不同标记及嵌套源码编辑由测试覆盖。 | U/T |
| M08 | 有序列表 | 从 3 开始的编号显示正确；缩进、续写、重编号和代码误判边界由测试覆盖。 | U/T |
| M09 | 任务列表 | [ ]、[x]、[/]、[?] 实际显示；Live 切换及撤销实际通过。任意单字符和其他扩展标记由测试覆盖。Read 无改写回调。 | U/T/C |
| M10 | 引用 | 多行、引用内列表实际显示；活动行 marker、嵌套和 continuation 由测试覆盖。 | U/T |
| M11 | Callout | 类型着色、+/- 初始状态、折叠箭头和未知类型回退；真实检查 tip 与 unknown，其他边界由测试覆盖。 | U/T |
| M12 | 围栏 / 缩进代码 | dart 高亮、长行折行、缩进代码实际显示；复制反馈、Tab、围栏长度和容器内代码由测试覆盖。 | U/T |
| M13 | GFM 表格 | 表头、列对齐、逐格编辑、撤销实际通过；编辑会规范化表格源码。内容驱动列宽有明显跳动。 | U/T |
| M14 | 表格结构操作 | 增行、增列、拖动行列、键盘跨格由组件与编辑器测试覆盖；本轮未把所有手势在真实设备重做。 | T |
| M15 | 外链与自动链接 | 外观渲染、源范围与解析有测试；桌面缺 onTapLink，真实点击外链没有预期动作。 | U/T/C |
| M16 | 相对路径、页内锚点 | 本地笔记与标题链接可见；桌面导航尚未接通，不能视为可打开。 | U/C |
| M17 | 引用式链接 | 完整/折叠/简写、定义大小写、重复定义与异常标签由测试覆盖；桌面导航仍受 M15 的边界限制。 | T/C |
| M18 | Wiki 链接和层级标签 | 别名、标题/块后缀、标签外观已解析；主样本可见，文件存在性查询与导航未接入桌面。 | U/T/C |
| M19 | 标准图片与尺寸 | 桌面当前显示 blocked 占位；组件支持尺寸、查看和编辑回调，成功加载、拖拽缩放不算桌面已实现。 | U/T/C |
| M20 | Wiki 嵌入 | 笔记、标题、块或图片引用由组件解析；桌面未接 resolver，只显示引用占位。 | U/T/C |
| M21 | Mermaid | 桌面显示 diagram 源码；组件有 builder，example 集成另有测试。 | U/T/C |
| M22 | 数学公式与货币 | 行内、块级公式实际渲染；$10 / $20 保持货币文本。无效 TeX、转义及源码范围由测试覆盖。 | U/T |
| M23 | 标准 / 内联脚注 | 重复引用编号、内联说明、文末定义可见；Live 保留编辑标记。点击导航需要宿主处理，桌面当前未接通。 | U/T/C |
| M24 | 注释、块 ID | Read 隐藏 %%注释%% 和有效块 ID，普通正文保留；Live 保留编辑信息。代码、转义和位置边界由测试覆盖。 | U/T |
| M25 | HTML 子集 | kbd/sub/sup/mark 样本可见；重复同类标签有回归测试。并非完整 HTML，单行 details 样本在 Read 不显示；特定多行 details 由组件测试覆盖。 | U/T/C |
| M26 | YAML front matter、水平线、不完整语法 | YAML 在 Live/Read 隐藏，Source 可编辑；水平线、Setext 及未闭合示例检查。typed YAML 与非完整语法边界有组件测试。 | U/T |

## 编辑深层行为与宿主选项（E01–E08）

| ID | 能力 | 结果 / 边界 | 证据 |
| --- | --- | --- | --- |
| E01 | 选区、跨块编辑、历史分组 | 文档统一文本模型；跨块选择、删除、快捷键及 undo 分组有测试。实际覆盖普通段落、任务、表格与恢复。 | U/T |
| E02 | 自动成对与键盘结构编辑 | 符号配对、跳过闭符、三反引号围栏、Backspace、Enter、Tab/Shift+Tab、列表续写由控制器/编辑器测试覆盖。 | T |
| E03 | 智能粘贴、富文本复制 | 选中文字后粘贴 URL 可生成链接；复制支持 Markdown 与过滤后的 HTML 表示。测试覆盖；未完整验证所有外部应用剪贴板格式。 | T |
| E04 | Properties 编辑 | 组件可选字符串/布尔/数字/日期、属性重命名、tags/aliases 芯片；桌面 showFrontMatter=false，用户需要 Source 编辑 YAML。 | T/C |
| E05 | 标题折叠 | 组件支持父子折叠、状态与目录展开祖先；桌面默认未启用。Callout 折叠是独立的已暴露能力。 | T/C |
| E06 | 渲染预算与降级 | 组件设解析预算与纯文本回退，相关测试通过；本轮 40 节样本仅为长文导航体验，不是性能压测或大文件基准。 | T/U |
| E07 | 无障碍、文字缩放、窄窗 | 本轮改善模式的名称/选择态/操作语义；840×560 测试检查当前标签可见。未进行完整 VoiceOver、全应用焦点顺序或 WCAG 审核。 | U/T |
| E08 | 文件访问与恢复边界 | UTF-8 严格解码、同目录临时文件写入、外部监听及 macOS 访问书签；异常与并发主要由测试覆盖，未模拟断电或所有文件系统。 | T/C |

## 常用快捷键

| 动作 | macOS 快捷键 | 说明 |
| --- | --- | --- |
| 新建 / 打开 / 打开目录 | ⌘N / ⌘O / ⌘⇧O | File 菜单同步 |
| 保存 / 另存为 / 关闭 | ⌘S / ⌘⇧S / ⌘W | 有保存取消与未存内容处理 |
| 撤销 / 重做 | ⌘Z / ⌘⇧Z | Read 不改写正文 |
| 粗体 / 斜体 / 链接 | ⌘B / ⌘I / ⌘K | 作用于编辑内容；搜索框应维持自身文本行为 |
| 删除当前行 | ⌘D | 编辑器命令，Read 拦截 |
| 全选 / 剪切 / 复制 / 粘贴 | ⌘A / ⌘X / ⌘C / ⌘V | 阅读态保留选择复制能力 |
| 缩进 / 反缩进 | Tab / Shift+Tab | 结构编辑或正常焦点移动，依上下文决定 |
| 切换前九个标签 | ⌘1–9 | 按当前标签顺序 |
| 切换侧栏 | ⌘⌃S | View 菜单同步 |

桌面通过按钮或 View 菜单选择模式。组件自身的模式数字快捷键与 ⌘E 已在桌面禁用，避免把标签快捷键误当成模式快捷键。
