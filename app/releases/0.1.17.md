# Linefold 0.1.17

- 修复目录改名时，正文无需修改的笔记因隔离标记等系统元数据而被错误阻止的问题；这类文件随原 inode 移动，扩展属性和正文保持不变。
- 将执行前被阻止与真正的部分完成分开提示，避免未改动文件时错误要求查看恢复记录。
- 同级目录改名时，不再因可证明不受影响的外部 Markdown 目录链接或非笔记链接而重复提示风险。
- 长行或解析预算限制不再一律阻止同级目录改名：无法安全验证改写的笔记保留原文，明确提示可能需要手动修复链接；不放宽正文改写、跨目录移动和事务核验的保护。
- 链接存在歧义时，详情显示具体目标及行号，方便定位；相关说明补充中文提示。

此版本继续通过 macOS 测试版分发。
