# Linefold 0.1.0 测试版

首个独立 macOS 应用测试版本，供收集反馈使用。

- Markdown 本地文档编辑、阅读与工作区搜索。
- Mermaid 渲染、文档导出与 Markdown Quick Look 预览。
- 本次构建使用本地文件模式，未启用应用专属 iCloud 容器。

下载与你的处理器匹配的 ZIP，解压后将 Linefold.app 拖入 Applications。
产物经过 Developer ID 签名与 Apple 公证；SHA256SUMS.txt 提供文件校验值。
此流程只生成 CI runner 对应架构的版本，不提供通用二进制或 iOS 安装包。

测试重要文档前请保留备份。问题反馈请附 macOS 版本、处理器型号和复现步骤。
