# Linefold 0.1.1 测试版

- macOS 发布构建启用默认 iCloud vault，与 iOS 使用同一个 Linefold 文档容器。
- 使用相同 Apple Account，并在两端开启 iCloud Drive；启动后默认打开 iCloud · Linefold。
- 编辑保存后由 iCloud Drive 自动同步。离线下载、同步和冲突状态仍以应用提示为准。
- 可继续手动选择外部文件夹；已有本地文件不会被默认上传，请将需要同步的文档复制到 Linefold iCloud vault。

下载 ZIP 并替换 Applications 中的 Linefold.app。此版本采用 Developer ID 签名、
iCloud 发布描述文件与 Apple 公证；原 0.1.0 本地模式安装包保持不变。

首个 iOS TestFlight 构建为 0.1.0 (1)，支持 Markdown 文件导入副本、预览、源码编辑、显式保存和文件夹授权编辑。
iOS 尚不包含桌面的完整工作区全文替换、模板及批量文件整理功能。
