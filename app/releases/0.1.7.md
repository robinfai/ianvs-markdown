# Linefold 0.1.7 — 测试版

- 扩展应用与 Finder 的大文档支持：共享渲染预算提高至 8,388,608 UTF-16 单元，Finder 文件读取上限提高至 32 MiB，并保留复杂段落保护。
- 优化大文档阅读与 Finder 的可视区域布局，减少重复解析、扫描及高亮计算。
- 修复仅保存滚动位置时触发工作区刷新、造成阅读模式长时间卡顿的问题。
- 保留大文档源码编辑、保存、全文复制以及阅读模式标题定位能力。

已使用真实 Angular、Deno 发布记录及 2.85 MB 合集，在实际 Finder 和应用中验证滚动与内存；另验证了 8.33 MB 普通段落压力文档。大表格首次布局仍可能出现短暂停顿。

本版继续提供签名、公证的 macOS DMG 和自动更新包。
